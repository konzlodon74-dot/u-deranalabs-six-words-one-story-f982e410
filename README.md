An entry for the make.fun bounty [Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410).

## What it does

`main.py` (Python 3.13, standard library only, no network) writes one complete
six-word story to `/output/entry.txt`, then re-reads the file and verifies it
holds exactly six words and 1–60 characters.

## The story

> He kept her seat warm. Forever.
